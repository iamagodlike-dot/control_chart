# Telegram-бот «Авто Академия» — INFOBOT

Показывает информацию о машинах, статусах и оплатах из базы сервиса прямо в Telegram.
Бот: **@autoacademyparser_bot**. Работает **только на чтение** — данные в базе не меняет.

## Что умеет (Этап 1)

- 🔎 **Найти авто** — по госномеру, имени клиента или № заказа → карточка машины
- 🚗 **Машины в работе** — список активных заказов по постам
- 👨‍🔧 **Загрузка мастеров** — сколько машин у каждого мастера
- 📊 **Сводка за день** — по кнопке (только управляющим)
- ☀️ **Утренняя сводка** — автоматически в 10:00, только управляющим

Финансы (счёт, остаток) в карточке видят только управляющие.

## Настройка

Всё хранится в файле `.env` (он не попадает в git):

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `SERVICE_ACCOUNT_PATH` | путь к ключу доступа к базе (файл `service-account.json`) |
| `SUMMARY_TIME` / `SUMMARY_TZ` | время утренней сводки и часовой пояс |
| `MANAGERS` | Telegram ID управляющих (через запятую) — финансы + утренняя сводка |
| `STAFF` | Telegram ID остальных сотрудников (через запятую) — без финансов |

### Ключ доступа к базе (service-account.json)

1. Firebase Console → проект **gannt-9b15d** → ⚙️ → **Project settings**
2. Вкладка **Service accounts** → **Generate new private key** → скачается файл JSON
3. Переименовать в `service-account.json` и положить в эту папку (`telegram-bot/`)

### Узнать свой Telegram ID

Написать боту `/start` или `/whoami` — он ответит номером. Этот номер добавляется в `MANAGERS` или `STAFF`.

## Запуск

```bash
npm install      # один раз
npm start        # запустить бота
```

Для работы 24/7 бота нужно разместить на постоянно включённом хостинге (обсуждается отдельно).

# Telegram-бот «Авто Академия» — INFOBOT

Показывает машины, статусы, запчасти, фото, документы и деньги из базы сервиса прямо
в Telegram. Бот: **@autoacademyparser_bot**.

## Что умеет

- **Найти авто** — списком кнопок или поиском (госномер, клиент, № заказа) → карточка
  машины с фото, запчастями, готовностью и документами
- **Машины в работе**, **Загрузка мастеров**, **Скоро выдача** — всем сотрудникам
- **Долги**, **Выручка**, **Аналитика**, **Сводка за день** — управляющим
- **Состояние ремонтов** — сводка учредителю (новые авто, согласования со страховой,
  укомплектованность по запчастям, счета к оплате)
- **Счета к оплате** — счета поставщиков файлом с кнопкой «Оплачено»
- **Почта** — разбор писем страховых, сверенный с базой машин
- Мгновенные уведомления: новая машина, готова к выдаче, поступила оплата, новый счёт
  поставщика, нужно заказать запчасти, счёт оплачен

Бот в основном читает; пишет он отметку оплаты счёта поставщика и свои служебные
записи (см. ниже).

## Настройки — на сайте, а не в .env

**Кто получает сообщения, во сколько приходят рассылки и какие уведомления включены —
настраивается на сайте:** app.academyauto.ru → **Настройки → Телеграм-бот** (раздел
виден только управленцу). Бот слушает эти настройки в реальном времени: правки
подхватываются за пару секунд, перезапускать его не нужно.

Как это устроено:

| Где | Что лежит |
|---|---|
| `settings/bot` | список людей с ролями, время и часовые пояса рассылок, тумблеры уведомлений. Правит сайт, читает бот (`botConfig.js`) |
| `settings/botStatus` | отметка «бот жив» — раз в 5 минут, по ней сайт показывает «на связи» (`control.js`) |
| `botCommands` | задания с сайта: «проверить связь», «отправить рассылку сейчас». Бот выполняет и дописывает результат туда же |

При первом запуске новой версии бот **сам переносит** содержимое `.env` в `settings/bot`
и ставит метку `seeded_from_env_at`. Если экран настроек успели открыть раньше, чем
обновился бот, при старте он один раз добавит своих людей из `.env` к тем, кто уже
указан на сайте — никто не потеряется.

Значения в `.env` остаются **страховкой**: если база недоступна, бот работает по ним,
как раньше.

### Что осталось в `.env` (только на сервере)

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `SERVICE_ACCOUNT_PATH` | путь к ключу доступа к базе (файл `service-account.json`) |
| `PHOTOS_BASE_URL` | откуда бот берёт фото машин |
| `MAIL_USER` / `MAIL_PASSWORD` / `MAIL_HOST` | доступ к почте по IMAP (пароль приложения) |
| `MANAGERS` / `STAFF` / `FOUNDERS` / `PARTSMEN` | первичный список людей — после переноса правится на сайте |
| `SUMMARY_TIME` / `REMINDER_TIME` / `FOUNDER_DIGEST_TIME` / `MAIL_DIGEST_TIME` + `*_TZ` | первичное расписание — после переноса правится на сайте |

### Ключ доступа к базе (service-account.json)

1. Firebase Console → проект **gannt-9b15d** → ⚙️ → **Project settings**
2. Вкладка **Service accounts** → **Generate new private key** → скачается файл JSON
3. Переименовать в `service-account.json` и положить в эту папку (`telegram-bot/`)

### Узнать Telegram ID сотрудника

Сотрудник пишет боту `/whoami` — бот ответит номером. Этот номер вводится на сайте в
«Настройки → Телеграм-бот». Пока человек не нажал в боте «Старт», сообщения ему не
дойдут — кнопка «Проверить связь» на сайте это сразу покажет.

## Запуск

```bash
npm install      # один раз
npm start        # запустить бота
```

Прод: VPS, папка `/opt/autoacademy-bot`, процесс под pm2 (`pm2 restart autoacademy-bot`).
Выкладка — rsync изменённых файлов в эту папку и перезапуск pm2.

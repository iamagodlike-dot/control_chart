# Наряд мастера + ЗП

> Исходный handoff-файл `handoff-naryad-mastera-zp.md` не был закоммичен и утерян;
> этот документ описывает реализованную функциональность.

## Что это

Две связанные вещи:

1. **Наряд мастера** — в «Себестоимости» машины работы из заказ-наряда
   распределяются по мастерам. У каждого мастера — сдельный процент от
   стоимости его работ (подставляется из справочника, правится по месту)
   плюс ручная доплата. По каждому мастеру печатается внутренний А4-лист
   «Наряд мастера» (работы, суммы, к выплате, подписи).
2. **ЗП** — вкладка «Зарплата» в «Финансах»: по каждому мастеру начислено
   (из себестоимостей машин), выплачено (транзакции-выплаты) и долг за всё
   время. Кнопка «Выплатить» создаёт транзакцию-расход.

## Модель данных

- `masters.rate_pct` — сдельный % мастера по умолчанию (справочник,
  «Настройки → Мастера»).
- `job.costing.services[]` — работы из ЗН с `master_id` (кто выполняет).
- `job.costing.labor[]` — строки оплаты: `{master_id, name, pct, amount}`,
  где `amount` — доплата. Итог строки считает `computeCosting()`:
  `total = (сумма работ мастера × pct/100) + amount` (см. `labor_rows`).
- Транзакция-выплата: `transactions` c `master_id`/`master_name`,
  категория «Зарплата мастера (сдельно)».

## Учёт без задвоения

Труд мастеров уже входит в себестоимость ремонтов (`labor_cost`), поэтому
транзакции с `master_id` **исключены** из «прочих расходов» P&L
(`computeFinance`), но **остаются** в кассовой ленте (`computeCashFlow`) —
это реальные деньги из кассы.

## Совместимость

Старые расчёты (без `services`/`pct`) работают как раньше: итог строки
оплаты равен введённой вручную сумме. Начисления старых расчётов, где
мастер записан именем без id, матчатся к мастеру справочника по имени.

## Ключевые файлы

- `client/src/costing.js` — работы с `master_id`, `labor_rows`.
- `client/src/payroll.js` — начислено/выплачено/долг по мастерам.
- `client/src/worksheet.js` + `components/MasterWorksheet.jsx` — печатный наряд.
- `client/src/components/PayrollView.jsx` — вкладка «Зарплата».
- `client/src/components/CostingModal.jsx` — распределение работ, печать наряда.
